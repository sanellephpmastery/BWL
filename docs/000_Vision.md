# BWL Vision

## Business Workflow Language

## Why BWL Exists

Modern software development requires developers
to repeatedly create the same infrastructure:

- Database models
- APIs
- Authentication
- Permissions
- Forms
- Workflows
- Reports
- Dashboards

Developers spend too much time writing repetitive code
instead of focusing on solving business problems.

## The BWL Idea

BWL allows developers to describe business processes.

The developer explains:

"What should the business do?"

The BWL compiler decides:

"How should the software be built?"

## Core Vision

BWL aims to make business software development faster,
simpler, and more maintainable.

BWL generates standard technologies:

- React
- Django
- Python
- PostgreSQL

without replacing proven technologies.

## Long Term Goal

BWL aims to become a complete ecosystem for building
business applications through:

- Business workflows
- Automatic code generation
- Plugins
- AI assistance
- Developer tools
